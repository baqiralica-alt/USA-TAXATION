README — How to Use This Workbook				
				
Purpose	Comprehensive US tax study workbook with live tax return models. Each return is populated with small sample data and linked formulas — change an input and watch the return recalculate.			
				
Color Code	Blue = input cell (you can change). Black = formula (don't change). Green = link to another sheet. Bold dark navy = total.			
				
2026 Rates	All rates are 2026 tax year. Standard deduction $16,100 single / $32,200 MFJ. SS wage base $184,500. QBI thresholds $201,750 / $403,500.			
				
Live Returns	Forms 1040, 1120, 1120S, 1065, 990, 941, 1040-ES. Each populated with fictional data. Every total is a formula — change an input and the totals update.			
				
State Coverage	Tab 10 has a state tax calculator with VLOOKUP from tab 11. Tab 11 lists all 50 states + DC with individual + corporate income tax rates and sales tax rates.			
				
Quick Reference	Tab 02 has all 2026 federal rates. Tab 12 has filing deadlines. Tab 13 has 100 US tax interview Q&A.
